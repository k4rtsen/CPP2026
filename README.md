# 💻 Изучение языка программирования C++

Репозиторий для учебных задач, упражнений и экспериментов по C++ из разных книг. Код организован по авторам и главам, чтобы легко сравнивать подходы и отслеживать прогресс.

## 📁 Структура репозитория

- `stroustrup/` — Бьярне Страуструп, *Programming: Principles and Practice Using C++* (2-е издания).
- `prata/` — Стивен Прата, *C++ Primer Plus* (6-е издание).
- `koenig/` — Эндрю Кёниг, Барбара Му, *Accelerated C++*.

## 🛠️ Стек и сборка

- **Компилятор:** `g++` (GCC с поддержкой `-std=c++20`)
- **Редактор:** VS Code
- **Флаги:** `-Wall -Wextra -g`

Компиляция отдельного файла из терминала:

```bash
g++ -std=c++20 -Wall -Wextra -g main.cpp -o main.exe
```
